# Design tokens

Tokens live in `src/styles/index.css` as Tailwind v4 `@theme` variables. They
compile to CSS custom properties (e.g. `--color-brand-600`) **and** unlock the
matching utilities (`bg-brand-600`, `text-neutral-700`, `rounded-card`, …).

## Non-colour tokens

| Token | CSS variable | Tailwind utility |
| --- | --- | --- |
| Card radius | `--radius-card` | `rounded-card` |
| Card shadow | `--shadow-card` | `shadow-card` |
| Hover shadow | `--shadow-card-hover` | `shadow-card-hover` |
| Font family | `--font-sans` | `font-sans` |

## Extending

Override any token from your own stylesheet after importing the package CSS:

```css
@import '@elevvo/react-ui/styles.css';

@theme {
  --color-brand-600: #0f766e; /* your brand colour */
}
```
